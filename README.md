# JS Page Source Fetcher

سكريبت بايثون بيفتح صفحات الويب باستخدام متصفح حقيقي عبر **Playwright** وبيجيب كود الصفحة.

## التثبيت

```bash
pip install playwright
playwright install chromium
```

## الاستخدام

1. غيّر قيمة `URL_YOU_WANT_TO_SCRAPE` في السكريبت إلى رابط الصفحة المطلوبة.
2. شغّل السكريبت:


سيتم جلب كود الصفحة.
